Grove Mail privacy policy

Effective November 2, 2026

Grove Mail is a personal tool used only by its owner, with the owner's own Google accounts. This page explains what Google data it touches and what happens to it.

Data it accesses

  • Gmail: message headers, message content and labels in the owner's own accounts. Grove Mail can apply and remove labels. It does not send, forward or delete mail.
  • Google Drive: read-only access to files in the owner's own Drive, used only when the owner asks.
  • Basic profile: the account's email address, so the tool knows which of the owner's accounts it is using.

How the data is used

The data is used only to help the owner keep up with his own mail and files: finding messages from specific people, summarizing them for him, and filing them into his own notes. Messages the owner's assistant reads may be processed by an AI assistant (Anthropic's Claude) that works on the owner's behalf for that purpose.

Storage

Sign-in tokens are kept on the owner's own computer, in a folder only Grove Mail can read. Any notes made from mail are kept in the owner's private files.

Sharing

Google user data is not sold, is not used for advertising, and is not shared with anyone other than the owner, except for the AI processing described above. No other people use Grove Mail.

Limited Use

Grove Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke Grove Mail's access at any time at myaccount.google.com/permissions. Revoking access stops Grove Mail from reading anything further.

Contact

Questions can be raised through the GitHub account MercuryTangent.
